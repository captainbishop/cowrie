# Security policy

Cowrie runs on Monad testnet with a test stablecoin. The contracts have not been audited, so please do not use them with real funds.

## Reporting a vulnerability

If you find a security issue, please open a private report through the repository's security advisories, or contact the maintainer directly rather than filing a public issue. Include steps to reproduce and the affected file. You can expect a first reply within a few days.
