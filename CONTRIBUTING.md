# Contributing

Thanks for taking a look. Cowrie is a hackathon project built on Monad testnet, and small fixes or ideas are welcome.

## Setup

Read the README for the two parts: the Hardhat contracts at the repo root and the Next.js app in `web/`. You need Node.js, a Monad testnet account with test MON for gas, and a Privy app id.

## Pull requests

- Keep each PR to one change with a short description of what and why.
- Match the existing style; the project uses plain TypeScript and Solidity 0.8.28.
- Do not commit secrets. `.env` and `web/.env.local` are gitignored for a reason.
- Say what you tested.

## Reporting bugs

Open an issue with steps to reproduce, what you expected, and what happened.
